# AI Accessibility Study Aids: Electric Current (Capstone 14)

Plain HTML, CSS and JavaScript. No backend, no install.

## Open in VS Code
1. Unzip, then File > Open Folder in VS Code.
2. Install the "Live Server" extension.
3. Right-click `index.html` > "Open with Live Server" (double-clicking index.html also works).

## Files
- index.html: all sections (Introduction, Study Notes, Audio Lesson, Mind Map, Quiz)
- style.css: design | script.js: text size, contrast, audio buttons, quiz
- assets/electric-current.mp3: ElevenLabs audio (AI-generated voice)
- assets/mindmap.jpg: mind-map picture (AI-generated)

## Edit
- Quiz: each `.q` block in index.html; data-a is the correct option number (0, 1, 2).
- Mind-map picture: replace assets/mindmap.jpg.
