# AI Accessibility Study Aids (Capstone 14)

Making one NCERT chapter easier to read, hear and see.

**Student:** Divyalakshmi.G
**Course:** AI Skills Course, Domain A: Education and Learning
**Source:** NCERT Class 10 Science, Chapter 11 "Electricity", Section 11.1 Electric Current and Circuit

## Problem
Dense textbook language is hard to read for students with dyslexia and for students still learning the language of instruction. Some students learn better by listening or by looking at pictures.

## Solution
One NCERT section was turned into three formats with AI, then checked line by line against the NCERT text:
- **Read:** simplified study notes
- **Hear:** a 2 min 30 s audio lesson (AI-generated voice, ElevenLabs)
- **See:** a six-branch mind-map
- **Quiz:** a five-question self-check

## Tools used
ChatGPT, Gemini, NotebookLM, Claude, ElevenLabs (free tier), and an image/design tool for the mind-map.

## Responsible AI
- All AI-generated content is labelled.
- Every output was checked against the NCERT text. Every tool made at least one error, so human review was needed.
- Only an open NCERT section was used, with credit. No personal data was uploaded.
- Known limit: the switch in the mind-map picture is still drawn open and is to be redrawn as closed.
